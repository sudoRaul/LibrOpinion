# Screenshots

Drop your captures here with **these exact file names** so the main `README.md` picks them up.
PNG recommended. Widescreen (desktop) captures look best in the gallery.

| File | What to capture |
|---|---|
| `landing.png` | The public landing page (light mode) — this is the hero image at the top. |
| `feed.png` | The home feed (`/app`) with a few quote cards. |
| `compose.png` | The “publish a quote” composer modal (with a book selected). |
| `profile.png` | A reader profile (`/u/:username`) with quotes and follower counts. |
| `quote.png` | A single quote permalink (`/q/:id`). |
| `notifications.png` | The notifications panel open (bell). |
| `admin.png` | The moderation panel (`/admin`) with a report and the ban modal. |
| `share-card.png` | An example of a quote shared as an image (the generated PNG). |
| `dark-mode.png` | Any view in dark mode (the feed or landing works great). |

Tip: use a consistent browser width (e.g. ~1280px) for the desktop shots so the gallery looks uniform.
